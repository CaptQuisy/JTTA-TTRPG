# Journey Through the Ages — System Reference Document (SRD)

**One System. Every Era. Endless Adventures.**

Welcome to the official System Reference Document (SRD) repository for **Journey Through the Ages (JTTA)**, a universal tabletop roleplaying game designed for realistic, character-driven adventures across history, the modern world, and the future.

JTTA uses a streamlined, skill-based system built around six-sided dice. Its rules emphasize meaningful character choices, tactical combat, realistic consequences, and flexible gameplay without sacrificing accessibility.

Whether exploring the Caribbean during the Golden Age of Piracy, fighting through the battlefields of World War II, investigating mysteries in the 1920s, or navigating the dangers of a distant future, JTTA provides a consistent set of rules adaptable to different settings and genres.

## About This Repository

This repository contains the **Journey Through the Ages System Reference Document**, organized into Markdown files for easy reading, searching, and referencing.

The SRD covers character creation, core mechanics, skills, combat, wounds and conditions, chases, vehicles, equipment, and other rules needed to play or develop adventures using the JTTA system.

The SRD is maintained as a living reference and may be updated as the game continues to develop.
